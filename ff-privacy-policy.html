💰 Finanzas Familiares

Política de Privacidad — Última actualización: Junio 2025
Resumen simple: Finanzas Familiares no recopila, almacena ni comparte ningún dato personal. Toda tu información financiera permanece únicamente en tu dispositivo.

1. Información que recopilamos

Finanzas Familiares no recopila ningún tipo de información personal. La aplicación no tiene servidor propio, no requiere registro de cuenta, no pide correo electrónico ni ningún dato de identificación.

2. Almacenamiento de datos financieros

Toda la información que ingresas en Finanzas Familiares (ingresos, gastos, presupuestos, categorías, transacciones) se almacena únicamente en tu dispositivo mediante el almacenamiento local del navegador (localStorage). Esta información:

  • Nunca sale de tu dispositivo
  • Nunca se envía a ningún servidor externo
  • Solo tú tienes acceso a ella
  • Se elimina si desinstala la aplicación o borras los datos del navegador

3. Datos financieros sensibles

Entendemos que los datos financieros son altamente sensibles. Por eso, Finanzas Familiares fue diseñada desde el principio para funcionar completamente sin conexión a servidores externos. Tus datos financieros jamás salen de tu dispositivo.

4. Permisos que usa la app

  • Almacenamiento local: para guardar tus registros financieros en el dispositivo
  • Acceso a internet: solo para cargar la aplicación desde GitHub Pages

La app no solicita acceso a cámara, micrófono, contactos, ubicación, cuentas bancarias ni ningún otro permiso sensible.

5. Servicios de terceros

Finanzas Familiares está alojada en GitHub Pages. Al acceder, GitHub puede registrar datos técnicos básicos como dirección IP, sujetos a la política de privacidad de GitHub.

La tipografía se carga desde Google Fonts, sujeta a la política de privacidad de Google.

6. Menores de edad

Finanzas Familiares es una aplicación de gestión financiera apta para uso familiar. No recopila datos de ningún usuario.

7. Cambios a esta política

Si en el futuro se realizan cambios, se publicarán en esta misma página con la fecha de actualización.
